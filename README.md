# BasicAPI
I am teaching myself APIs and Python with this repo! It is a simple test API and API template. I'll develop it more to demonstrate my progress, and maybe serve as a learning tool for others!

This project is made completely without AI, so yay debugging and development are really slow. Anyway, I'm doing my best to keep my references in citations.txt. There's a lot of those!

If you want to spin up a quick API, use template.py. It will be a historical basic template point. As the project progresses, the template will stay relatively unchanged.

Start the API with "uvicorn main:app --host 0.0.0.0 --port 1337" in the directory.
